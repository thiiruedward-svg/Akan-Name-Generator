#Akan Name Generator

##Project description 
A web application that calculates the day of the week a person was born and assigns an Akan name based on their birth date and gender.

## Setup Instructions
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in a web browser.
4. Enter a birth date and select a gender.
5. Click the Generate My Akan Nae button.

## Behaviour-Driven Development (BDD)

Feature: Generate an Akan name

Scenario: A user enters a valide birth date given the user enters a valid birth date and the user selects a gender when the user user submits the form then the application displays the weekday and the correct Akan name for that gender.

Scenario: A user enters an invalid date given the user enters an impossible date when the user submits the form then the application displays an alert.
